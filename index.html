Step 01

Add Recurring Meetings

Add each meeting that repeats on specific rotation days (Day 1–8), or on regular weekdays. Every meeting only lands on actual school days. Pick a day first — the block list then shows exactly what's meeting in each slot that day.

Meetings landing on a Two-Hour Delay day (Oct 14, Nov 11, Dec 2, 2026 or Feb 24, 2027) get flagged LATE START in the title, with times shifted automatically. Meetings on Oct 30, 2026 or Mar 2 & 5, 2027 get flagged CHECK 4 SPECIAL SCHED. — those run a modified schedule too, but times aren't auto-adjusted.

Applies to every meeting below — whoever runs this export is the organizer for that batch.

How To

Importing Into Outlook

Once you've downloaded your .ics file, you have two ways to bring it into Outlook.

Option A Import to Your Primary Calendar

Adds events directly into your main calendar. Simple, but to remove them later you'll need to delete each event one at a time.

  1. Open Outlook and go to File → Open & Export → Import/Export
  2. Choose Import an iCalendar (.ics) or vCalendar file and click Next
  3. Browse to your downloaded .ics file and select it
  4. Click Import
Option B Add as a Separate Calendar

Creates a new calendar layer you can show, hide, or delete all at once — recommended if you'll re-import each semester.

  1. Open Outlook's Calendar view
  2. Right-click My Calendars → Add Calendar → Create New Blank Calendar
  3. Name it, e.g. "Spring Meetings"
  4. Right-click it → Import, then select your .ics file
Inviting Others

If you filled in the Attendees field on a meeting, those emails are baked into every occurrence of that meeting. But importing a file only ever creates a personal appointment in Outlook — it can't dispatch an actual invitation or start RSVP tracking on its own. Open the event, confirm the attendees showed up (Outlook may or may not carry them over from an imported file — this varies), and hit Send to actually invite them. Since each recurring meeting imports as a separate event rather than a single Outlook series, that's one Send per occurrence you want shared — there's no one click that invites people to the whole run at once.

Before you hit Send — check Response Options → Request Responses is turned on. This is what actually enables RSVP tracking, separate from just having attendees listed. Events built from an imported file (like these) don't reliably default this to on the way a brand-new Outlook meeting does — confirmed by testing, one imported event showed "You haven't requested responses for this event" under Tracking even with an attendee added and the invite sent. Look for it near the attendees / Scheduling Assistant area, or under a "…" more-options menu in the compose window.

Two things make the Send step faster:

  • Search + List view — in Outlook's Calendar search bar, type subject:"Meeting Name" and press Enter. Results switch to List view as a flat, clickable list instead of scattered across the month grid, so you can move through every occurrence quickly.
  • A Contact Group for the recurring attendees — set one up once under People → New Contact Group (e.g. "Dept Chairs Committee"). Then for each event, just type that group's name into Invite Attendees instead of re-adding people individually every time.
